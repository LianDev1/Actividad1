## Resumen del Proyecto
Este repositorio contiene el desarrollo práctico de los primeros 14 ejercicios del Tema 2. El objetivo principal es la maquetación estructurada con HTML5, el estilizado mediante hojas de estilo CSS3 y la implementación de lógica básica interactiva usando JavaScript.
