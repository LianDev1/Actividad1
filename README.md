## Resumen del Proyecto
Este repositorio contiene el desarrollo práctico de los ejercicios del **Tema: HTML**
y del **Tema 2: Fundamentos de Estructura, Contenido, CSS y JavaScript**, realizados
en clase de Programación Web.

## Cómo ejecutar el proyecto
1. Colocar la carpeta del proyecto dentro de `C:\xampp\htdocs\`
2. Iniciar el servidor Apache desde el panel de control de XAMPP.
3. Abrir en el navegador: `http://localhost/<nombre-de-la-carpeta>/`
